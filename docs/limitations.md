# 当前局限

- **验证范围很窄**：详细分析只在公开比赛视频的一个回合上验证过；还没分析用户本人的比赛。运行环境笔记另有第二段视频的速度及一致性测试，这不等于第二份完整的教练分析验证。
- **还需要人工**：场地标定和逐拍击球均需复核。声音检测会受背景声影响；没有对手标签时，准备时间使用候选声估计。当前不是录完即得结论的自动陪练。
- **触球精度有限**：25–30fps 下，触球帧精度约一帧。这是本次任务给定的工作估计，未在笔记中找到独立精度测试；帧率量化之外还可能有音画不同步和检测误差，不应承诺精确到某一瞬间。
- **骨骼并不总可靠**：高速挥拍时手腕、手臂会丢失，观众可能被识别为球员；两人同框时身份排序可能错误。背后机位膝角和反应时间禁用。
- **场地位置也有误差**：标定交点拟合误差不等于动态定位精度；晃动、遮挡、误匹配、脚部识别和透视均会影响结果。位置跨中线时左右计数不稳定，跑动距离只报范围。
- **运行环境会影响结果**：不同处理器平台的两人骨骼追踪曾有分歧，同一人的历次分析宜固定在同一环境。原依赖快照是空文件，本仓库下限是整理用兼容基线，不是完整恢复的原环境。
- **对比仍为样片脚本**：片段与触球时刻手工指定；全身片段仍按原脚本在 0.8 秒起取 1.52 秒、以 25fps 采样，固定裁切 `360:420:400:300`、触球帧索引 19。自动裁切需要可靠骨骼，未检测到骨骼时可能失败；窗口、ROI 与视频尺寸不匹配也可能失败。前后机位不同只能辅助观察，不能直接比较方向或精确关节角。公开整理没有改动这些算法或固定样片假设。
- **高手库没有授权素材**：演示用第三方公开比赛画面，不随代码公开；公开可访问不代表获准再发布。正式动作库尚需授权或自录示范。
- **设备链路待接通**：此仓库没有摄像头实时采集、大屏控制或自动关键动作选择的实现。对比脚本还使用旧版 MediaPipe Solutions API，依赖需保持兼容。
- **本次没有重跑视频分析**：这里只检查源码编译、入口帮助和依赖接口。无素材和模型的公开目录不能证明完整流水线在新环境下重现历史结果。

下一步围绕授权素材、自动选片和大屏联动做现场原型；先缩短分析链路，再验证响应时间与球友实际使用效果。历史单回合结果不应作为对任何球友的既定判断。
